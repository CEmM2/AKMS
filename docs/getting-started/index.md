# Getting started

AKMS ships as four packages that share one graph substrate. Start with the
core, add the others when their workflow applies to you.

| Start here | When |
|---|---|
| [AKMS Core overview](akms/overview.md) | Always — every other package builds on the core graph, task-context, and loadout pipeline. |
| [Installation](akms/installation.md) → [Quick start](akms/quickstart.md) | Get a graph compiled and queried in minutes. |
| [MCP server](akms/mcp.md) | Expose the graph to an MCP-capable agent instead of the CLI. |
| [Failure Memory](failure-memory.md) | Record lessons from failed runs and project them into future task context. |
| [akms-learn](akms-learn.md) | **Experimental preview** — turn source material into structured learning notebooks. |
| [Node generation](nodes-gen/install.md) | Author new knowledge nodes from papers or code at scale. |
| [Agent skills](agent-skills.md) | Drop-in skill directories that teach a coding agent the whole loop. |

If you are deciding *how* to use AKMS rather than how to install it, read
[Choose a workflow](../concepts/workflows.md) first.
