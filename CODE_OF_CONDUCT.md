# Code of conduct

This project follows a simple standard: be professional and be kind.

**Expected**: respectful technical discussion, good-faith reviews, credit for
others' work, patience with newcomers.

**Unacceptable**: harassment, personal attacks, discriminatory remarks,
sustained disruption, publishing others' private information.

Maintainers may edit or remove contributions and comments that violate this
standard, and may block repeat offenders. Report conduct issues privately to
the maintainer (see `AUTHORS.md`); reports are handled confidentially.
