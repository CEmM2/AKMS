# Notation Cheatsheet: Configurations, Stresses & Operations

## Summary

Compact single-page reference for all mathematical symbols used across the codebase. Covers configurations (reference/current), kinematic quantities (F, C, b, E), stress measures (Cauchy, PK1, PK2, Kirchhoff), push-forward/pull-back operations, multiplicative split for finite-strain plasticity, phase-field parameters, and FFT-Galerkin conventions. Serves as the authoritative lookup for symbol meanings.
