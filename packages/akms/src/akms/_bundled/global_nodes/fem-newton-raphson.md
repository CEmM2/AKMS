# Newton-Raphson & Nonlinear Solution

## Summary

The Newton-Raphson method solves systems of non-linear algebraic finite element equations by iteratively linearizing the internal nodal force vector using the consistent tangent stiffness matrix. Convergence is accelerated or stabilized using line searches based on quadratic interpolation or bisection, and path-following arc-length methods (such as Riks' formulation) enable traversal of limit points and snap-through instabilities.

## 1. Core Concept

Non-linear continuum mechanics discretizations yield algebraic systems governed by internal force equilibrium. The Newton-Raphson method computes iterative correction steps to the displacement vector by factorizing the tangent stiffness matrix and solving linear residual systems. To maintain quadratic asymptotic convergence rates, the tangent matrix must be consistently linearized with respect to the constitutive return mapping algorithm. When full Newton iterations diverge or slow down near limit points or local instabilities, line search scaling parameters or arc-length constraint equations are introduced to enforce energy dissipation or navigate snap-through/snap-back responses.

## 2. Mathematical Formulation

**Non-Linear Residual Equilibrium**
$$
r(a) = f^{\mathrm{ext}} - f^{\mathrm{int}}(a) = 0
$$
_Source: Borst_Crisfield_2012_Nonlinear finite element analysis of solids and structures.pdf, Sec. 2.4, Eqs. 2.42 & 2.45, pp. 44–46; Belytschko_Nonlinear Finite Elements for Continua and Structures.pdf, Box 6.4, p. 345_

**Newton-Raphson Linearized Iteration**
$$
K_j \Delta a_{j+1} = r_j, \quad a_{j+1} = a_j + \Delta a_{j+1}
$$
_Source: Borst_Crisfield_2012_Nonlinear finite element analysis of solids and structures.pdf, Sec. 2.4, Eqs. 2.43–2.50, pp. 44–46; Belytschko_Nonlinear Finite Elements for Continua and Structures.pdf, Box 6.6, p. 375_

**Line Search Energy Dissipation Criterion**
$$
s(\eta) = (\Delta a_{j+1})^T r(a_j + \eta \Delta a_{j+1}) = 0
$$
_Source: Borst_Crisfield_2012_Nonlinear finite element analysis of solids and structures.pdf, Sec. 4.1, Eqs. 4.1–4.4, pp. 113–115_

**Arc-Length Constraint Equation**
$$
(\Delta a_{j+1})^T \Delta a_{j+1} + \beta^2 (\Delta \lambda_{j+1})^2 (f^{\mathrm{ext}})^T f^{\mathrm{ext}} = (\Delta l)^2
$$
_Source: Borst_Crisfield_2012_Nonlinear finite element analysis of solids and structures.pdf, Sec. 4.2, Eqs. 4.14–4.18, pp. 117–119_

**Notation:**
{'a': 'Global vector of nodal displacement degrees of freedom.', 'f^{\\mathrm{ext}}': 'Vector of external applied nodal forces.', 'f^{\\mathrm{int}}': 'Vector of internal nodal forces generated by element stresses.', 'r': 'Unbalanced residual force vector r = f^{\\mathrm{ext}} - f^{\\mathrm{int}}.', 'K': 'Global tangent stiffness matrix K = \\partial f^{\\mathrm{int}} / \\partial a.', '\\eta': 'Line search step-length scaling parameter.', '\\lambda': 'Scalar load multiplier parameter in arc-length solvers.', '\\Delta l': 'Prescribed arc-length path increment.'}


## 3. Algorithmic Implementation

**Newton-Raphson Incremental-Iterative Solution Procedure**
$$
\begin{algorithmic}
\State $Initialize displacement state a \gets 0, external load vector f^{\mathrm{ext}} \gets 0$
\For{$n \gets 1 \text{ to } N$}
\State $Update external force f^{\mathrm{ext}} \gets f^{\mathrm{ext}} + \Delta f^{\mathrm{ext}}$
\State $Compute tangent stiffness K \gets \mathrm{assembleStiffness}(a) \text{ and internal force } f^{\mathrm{int}} \gets \mathrm{assembleInternalForce}(a)$
\State $Compute residual vector r \gets f^{\mathrm{ext}} - f^{\mathrm{int}}$
\While{$\|r\| > \mathrm{tol}$}
\State $Solve linear system K \Delta a \gets r$
\State $Update displacement vector a \gets a + \Delta a$
\State $Re-evaluate K \gets \mathrm{assembleStiffness}(a) \text{ and } f^{\mathrm{int}} \gets \mathrm{assembleInternalForce}(a)$
\State $Recompute residual vector r \gets f^{\mathrm{ext}} - f^{\mathrm{int}}$
\EndWhile
\EndFor
\Return $a$
\end{algorithmic}
$$

## 4. Known Pitfalls

- **Divergence at Limit Points and Snap-Through**: Standard load-controlled Newton-Raphson iteration fails to converge near limit points or snap-through instabilities where the tangent stiffness matrix K becomes singular or ill-conditioned. Mitigation: Switch from load control to displacement control or path-following arc-length methods (such as Riks' technique) to navigate past limit points. _(Source: Borst_Crisfield_2012_Nonlinear finite element analysis of solids and structures.pdf, Sec. 2.5, pp. 50–53 & Sec. 4.2, pp. 116–118)_
- **Inconsistent Tangent Operator Causing Loss of Quadratic Convergence**: Using a continuum elastic-plastic tangent matrix instead of the algorithmic consistent tangent matrix derived from the implicit return mapping algorithm reduces the asymptotic convergence rate of the global Newton-Raphson loop from quadratic to linear. Mitigation: Compute and assemble the algorithmic consistent tangent modulus C^{\mathrm{alg}} corresponding exactly to the discrete stress update scheme. _(Source: Belytschko_Nonlinear Finite Elements for Continua and Structures.pdf, Box 6.6, p. 375; Borst_Crisfield_2012_Nonlinear finite element analysis of solids and structures.pdf, Sec. 7.5, p. 251 & Box 7.7, p. 252)_
